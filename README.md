# IT Elective 2 - Finals Exam

**Class/Section:** BSIT31E2
**Subject:** IT Elective 2 – Web Systems and Technologies

## About
This is an ASP.NET Core MVC application that displays each students' portfolio. 
Each portfolio contains previous projects / works done for IT Elective 2 – Web Systems and Technologies.
Projects can be viewed on GitHub by clicking the project card. Every student contributed in making their own controllers and adding views and models
on the repository by committing changes and PRs. Each pull request is reviewed and approved by selected students. Conflicts in merging are also resolved.

## TECHNOLOGIES USED
- ASP.NET Core MVC (.NET)
- C#
- Razor Views (.cshtml)
- Bootstrap for styling

## RUN the System

* **1. Download ZIP or Clone the repo:** In the GitHub repo, click "Code" and choose **"Download ZIP"**. Alternatively, clone using the link then proceed to step 5.
* **2. Extract All:** If zipped, select the downloaded .zip file and extract.
* **3. Find file location:** Open the folder then open **IT_ELECTIVE_2_FINAL_EXAM_BSIT_31E2**.
* **4. Open the System:** Find **IT_ELECTIVE_2_FINAL_EXAM_BSIT_31E2.slnx** and open with Visual Studio.
* **5. Run:** Click **Run (http)** in Visual studio or press **F5**.
* **6. Open in web:** If the localhost doesn't open automatically, take note of the localhost port in the console and open it in your preferred browser.
